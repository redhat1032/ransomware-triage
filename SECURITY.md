# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.3.x   | Yes       |
| < 0.3   | No        |

## Reporting a vulnerability

If you find a security problem in ransomtriage (for example unsafe handling of a malicious note, regular-expression
denial of service, or path issues), please report it privately:

1. **Do not open a public issue.**
2. Use GitHub's private vulnerability reporting: the **Security** tab of
   https://github.com/redhat1032/ransomware-triage, then **Report a vulnerability**.
3. Include steps to reproduce and any sanitised sample files.

You should get an acknowledgement within a few days.

**This project cannot help decrypt files or respond to an active incident.** If you are a victim, contact your
national authority (in the US, [CISA](https://www.cisa.gov/report) and [FBI IC3](https://www.ic3.gov/)) and check
[No More Ransom](https://www.nomoreransom.org/).
